# 《韭菜收割者》隐私政策

更新日期：2026年11月6日

《韭菜收割者》（以下简称"本游戏"）由马仔游戏工作室（以下简称"我们"）开发。我们非常重视您的个人信息保护。本政策说明本游戏如何处理（包括收集、存储、使用）您的个人信息，以及您享有的相关权利。

## 一、我们收集的信息

本游戏是一款纯前端单机游戏。在您使用本游戏过程中，我们**不会收集、上传或存储**任何可识别您个人身份的信息，包括但不限于：姓名、电话号码、身份证件号码、位置信息、通讯录、相册等。

为维持游戏功能所必需，本游戏会在**您的浏览器本地（localStorage）**保存以下数据，这些数据仅存储在您自己的设备上，不会上传至我们的服务器：

- 游戏存档（关卡进度、解锁的角色与武器、金币数量等）；
- 游戏设置（音量、操作偏好等）。

您可以随时通过清除浏览器数据来删除上述本地数据。

## 二、我们不使用的权限

本游戏不会申请或使用以下权限：定位、相机、麦克风、通讯录、存储读写（除浏览器本地存储外）。

## 三、第三方服务

本游戏通过 TapTap 平台分发与运行。当您通过 TapTap 启动本游戏时，TapTap 平台会按照其自身的隐私政策处理相关数据。详情请查阅 TapTap 的《隐私政策》。

除此之外，本游戏不接入任何第三方统计、广告或分析 SDK。

## 四、未成年人保护

本游戏不包含社交、充值或付费功能。我们建议未成年人在监护人陪同下使用，并注意合理安排游戏时间。

## 五、政策更新

我们可能适时修订本政策。修订后的政策将在本页面发布，重大变更时我们会以显著方式提示。

## 六、联系我们

如果您对本政策或个人信息保护有任何疑问、意见或建议，可通过 GitHub 仓库 Issues 联系我们：https://github.com/ns2250225/jiucai/issues
