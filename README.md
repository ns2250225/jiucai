# 韭菜收割者 The Great Leek Harvest

> 让每一根韭菜都实现自己的价值，然后被收割。

一款以「韭菜」为主题的荒诞黑色幽默像素风 **Roguelike 生存割草** 游戏。玩家扮演神秘的韭菜收割者，手持不断进化的镰刀闯入各大韭菜田，在成群结队的韭菜中走位、收割、升级、构建流派 —— 而韭菜们也会逐渐学习你的战斗方式、组织反抗，甚至发动「韭菜起义」。

**纯前端单机游戏**：无后端、无账号，存档保存在浏览器本地，支持 PWA 安装到桌面。

## ✨ 特性

- **爽快割草**：同屏大量韭菜，自动攻击 + 范围攻击 + 连锁攻击，配合飘字、粒子和音效的密集击杀反馈。
- **韭菜反进化系统**：韭菜不是靶子 —— 它们会监控你的战斗习惯（行为监控），逐步获得抗性、护甲、走位甚至组织战术；战场上还有韭菜科技中心、进化核心等可摧毁目标。
- **镰刀组合进化**：12 把基础镰刀 × 10 种进化形态。主武器满级 + 指定被动道具即可进化（如：普通镰刀 + 贪婪之心 → 黄金收割者）；进化武器之间还能触发**组合羁绊**（如：雷霆黑洞、烈焰风暴、极寒光束）。
- **6 名角色**：神秘收割者、贪婪资本家、疯狂农夫、闪电收割者、黑洞博士、末日审判官，各带专属大招与流派定位。
- **7 张地图 × 7 个 BOSS**：从新手韭菜田一路割到资本之巅，牛市收割场、熊市深渊、科技韭菜实验室……每张地图独立出怪表与节奏，最终面对「韭菜联合会主席」。
- **35 种韭菜敌人**：普通韭菜、老韭菜（回光返照）、逃跑韭菜、科学家韭菜、反抗军……各有 AI 行为与反进化反应。
- **24 种随机事件**：韭菜暴涨、市场崩盘、天降金币、强制平仓、恶意收购……把金融市场的荒诞搬进战场。
- **局外成长**：金币商店永久强化、角色皮肤、称号、成就系统，以及韭菜图鉴 / 武器图鉴收集。
- **全程序化美术**：项目内没有任何图片资源，所有像素画、图集、动画均由代码在运行时绘制生成（`src/game/art/`）。
- **双端操作**：PC 键盘 + 移动端横屏虚拟摇杆，响应式 UI。

## 🎮 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动（攻击全自动） |
| Space | 大招 |
| 1 / 2 / 3 或鼠标点击 | 升级三选一 |
| ESC | 暂停 |

移动端：横屏使用，左下角虚拟摇杆移动，其余全部自动。

## 🚀 快速开始

```bash
npm install
npm run dev       # 本地开发（自动局域网可访问）
npm run build     # 类型检查并打包到 dist/
npm run preview   # 预览打包结果
```

要求 Node.js 18+。打开终端输出的地址即可游玩。

## 🛠 技术栈

| 层 | 技术 |
|---|---|
| 游戏引擎 | [Phaser 3](https://phaser.io/) |
| UI 框架 | [Vue 3](https://vuejs.org/)（`<script setup>`） |
| 状态管理 | [Pinia](https://pinia.vuejs.org/) |
| 构建 | [Vite](https://vitejs.dev/) + TypeScript |
| 美术 | 运行时程序化像素画（Canvas 绘制 + 图集打包） |
| 存储 | localStorage 存档 + PWA（manifest / Service Worker） |

架构上 Vue 负责 UI 层（主菜单、升级面板、图鉴、商店等），Phaser 负责战斗场景，两层通过 Pinia store 与事件桥接。

## 📁 目录结构

```
src/
├── components/        # Vue UI 组件（主菜单、HUD、升级、商店、图鉴、虚拟摇杆等）
├── data/              # 局外数据：角色、成就、局外强化、皮肤、称号
├── game/
│   ├── art/           # 程序化像素美术：画笔、图集、韭菜/道具绘制
│   ├── data/          # 游戏内容表（JSON）：武器、敌人、BOSS、地图、技能、进化、事件
│   ├── entities/      # 实体：玩家、韭菜、精英、BOSS、投射物
│   ├── evolution/     # 韭菜反进化：行为监控、进化事件、抗性系统
│   ├── scenes/        # Phaser 场景：Boot / Preload / Menu / Battle / Result
│   ├── skills/        # 被动、技能、大招管理
│   ├── systems/       # 战斗、伤害、掉落、刷怪、事件、经验、特效、输入、对象池
│   └── weapons/       # 7 类武器行为（近战/环绕/投射/范围/光束/召唤）+ 进化
├── services/          # 音频、存档
└── stores/            # Pinia：游戏、玩家、成就
```

## ⚖️ 数值与改表

游戏内容全部数据驱动，改表即改游戏，无需动代码：

- `src/game/data/weapons.json` —— 武器属性、成长、进化
- `src/game/data/enemies.json` —— 敌人属性与反进化反应
- `src/game/data/maps.json` —— 地图主题、出怪波次、BOSS
- `src/game/data/skills.json` —— 被动道具
- `src/game/data/evolutions.json` —— 武器进化表与组合羁绊
- `src/game/data/events.json` / `bosses.json` —— 随机事件 / BOSS
